# Contribuições

Sugestões e relatos de problemas são bem-vindos. Não envie credenciais, logs com dados sensíveis, código de clientes/empregadores ou projetos de terceiros.

Leia `LICENSE` antes de usar ou modificar o código: a autorização padrão é somente para uso pessoal e estudo não comercial. A publicação no GitHub não concede autorização comercial.

Antes de incorporar uma contribuição externa de código, será necessário confirmar sua autoria, ausência de restrições de empregadores/terceiros e condições que permitam seu uso e licenciamento pela titular. Um pull request, por si só, não transfere a titularidade dos direitos autorais. Não copie implementações de outros projetos para dentro desta ferramenta.

Solicitações de licença comercial devem ser dirigidas a Déborah Fernandes pelo perfil https://github.com/deefaraujo. Não publique informações comerciais confidenciais em issues públicas.
