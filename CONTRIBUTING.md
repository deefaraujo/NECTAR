# Contributing

Suggestions and bug reports are welcome. Do not submit credentials, logs with sensitive data, code from clients or employers, or third-party projects.

Read `LICENSE` before using or modifying the code: the default authorization covers personal use and non-commercial study only. Publication on GitHub does not grant commercial authorization.

Before an external code contribution is incorporated, its authorship, the absence of employer or third-party restrictions, and terms that allow its use and licensing by the owner will need to be confirmed. A pull request on its own does not transfer copyright ownership. Do not copy implementations from other projects into this tool.

Commercial license requests go to Déborah Fernandes through https://github.com/deefaraujo. Do not post confidential business information in public issues.
