# Manual organizer

The ✓ option opens `/avaliacoes.html`. It lets you manually record an operational task, shift, step, wait, pending item and resume point.

The panel does not call models, evaluate transcripts, generate prompts or justifications, or submit work to external platforms. Check the rules of any service before using it in a workflow regulated by third parties.

Use "Salvar ponto de retomada" before closing. Switching records saves valid changes to the previous one. Pending changes are indicated; there is no guarantee of saving after an abrupt shutdown.

Records are kept in `avaliacoes-operacao.json` in the private data folder. There is version control against overwrites by another window, and manual export to JSON. Do not put credentials or confidential material in the notes.

The status is a personal note, not a confirmation of approval or submission through an external service.
